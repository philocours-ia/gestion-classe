# 📚 Dashboard Scolaire – Gestion des Élèves

Application web légère et moderne pour la gestion quotidienne d’une classe ou d’un établissement scolaire.

## ✨ Fonctionnalités

- **Liste des élèves** : ajout, suppression et affichage des élèves
- **Registre d’appel** : enregistrement des présences, retards et absences par date
- **Rapports journaliers** : consultation des retards et absences
- **Feuille de notes** : saisie des notes par matière (Philosophie, Mathématiques, Malagasy, Français, Anglais, EPS, Physiques, SVT, Histo-Géo)
- **Générateur de bulletins** : création rapide de bulletin avec moyenne générale

Toutes les données sont sauvegardées automatiquement dans le `localStorage` du navigateur.

## 🚀 Utilisation

1. Télécharge les deux fichiers :
   - `dashboard.html`
   - `README.md` (ce fichier)

2. Ouvre simplement `dashboard.html` dans ton navigateur (aucune installation requise).

3. Commence par ajouter des élèves dans l’onglet **Liste des élèves**.

## 📋 Navigation

- **Liste des élèves** : gestion des élèves
- **Registre d’appel** : prise d’appel quotidienne
- **Rapports journaliers** : historique des appels
- **Feuille de notes** : saisie des notes
- **Générateur de bulletins** : impression / export des bulletins

## 🛠️ Technologies utilisées

- HTML5 + Tailwind CSS (via CDN)
- Font Awesome 6
- JavaScript vanilla (aucune dépendance externe)
